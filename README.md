# Backend Engineering Learning Notes

Study guides and interview preparation for backend engineers. Each guide explains the idea first, lists the tools to master, shows common mistakes, and ends with self-check and interview questions.

**Status:** personal study notes, written with AI assistance. Most guides in `01` to `15` were checked against official documentation on 2026-11-06. Items that could not be verified are marked in the text. File `16` and the course folders were not fully fact-checked. No code in these guides was run. Check version-specific details against current official docs before relying on them.

## How to study

1. Read a chapter once.
2. Answer its self-check questions without looking.
3. Re-read only what you missed.
4. Practise on a real project.
5. Use the interview banks last, level by level.

No guide can promise a job offer. These notes aim to make your preparation more complete.
